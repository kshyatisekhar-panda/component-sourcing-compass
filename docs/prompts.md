# Demo prompts

Type these into Cline during the demo. For internal LLM prompt reference (tool descriptions, system prompts, agent rules), see [internal-prompts.md](internal-prompts.md).

1. List the components in the LE 3.
2. Cost breakdown for the LE 3.
3. How has the 3 kW IE3 motor's price moved over the last year?
4. Compare the LE 3's top components to Mouser. Which should we switch?
5. Which component change has the biggest impact across our LE 3, LE 7, LT 3, and LF 7?
6. Can we sell the LE 3 in the EU?
7. What about the US?
8. Which SVHC substance triggered the EU flag and when did ECHA add it?
9. Generate an EU compliance certificate for the LE 3.
10. Now generate a US one to compare.
11. Plan an EU launch for the LE 3: costs and compliance fixes.
